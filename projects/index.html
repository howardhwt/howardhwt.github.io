Startup · co-founded · building

Salency

A memory layer between sales call notetakers and the CRM. It pulls pains, objections, contradictions and commitments out of every call, with a citation for each, so the rep who inherits an account reads the whole story.

My first go at founding, with a small team.

Handheld OS · C · open source

Bramley

An Apple inspired system for the TrimUI Brick handheld, forked from NextUI. A home screen with Continue Playing, a game library, a music player with audiobook bookmarks, a lock screen and iPad style Settings.

The launcher now starts in about 650 ms instead of 940, and if it fails to start twice, stock NextUI opens so a bad build never locks you out.
